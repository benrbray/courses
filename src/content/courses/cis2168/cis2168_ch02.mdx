### 2.1 Algorithm Efficiency and Big-O

The exact runtime of a program depends on many complex factors (hardware, caching, network speed, etc.)

> Because it is very difficult to get a precise measure of the performance of an algorithm or program, we normally try to approximate the effect of a _change_ in the number of data items $n$, that the algorithm processes.  In this way, we can see how an algorithm's execution time changes with respect to $n$, so we can compare two algorithms by examining their growth rates.
