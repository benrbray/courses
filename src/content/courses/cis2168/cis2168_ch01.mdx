### Section 1.4:  Abstract Classes

An **abstract class** differs from an ordinary _concrete_ class in two ways:

- an abstract class cannot be instantiated
- an abstract class may declare abstract methods

Abstract classes are like interfaces, in that they are used to define a _contract_ that describes the expected behavior of an abstract data type.  Unlike data types:

- an abstract class can define attributes
- an abstract class can provide default implmentations of some methods, and leave other methods *abstract* to be defined by the implementor

**Example:** Food Pyramid

```java
public abstract class Food {
  // Data Field
  private double calories;
  // Abstract Methods
  public abstract double percentProtein();
  public abstract double percentFat();
  public abstract double percentCarbohydrates();
  // Actual Methods
  public double getCalories() { return calories; }
  public void setCalories(double cal) {
    calories = cal;
  }
}
```
