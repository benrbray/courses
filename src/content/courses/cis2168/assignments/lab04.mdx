## Problem 2:  Circular Array Deque

A **double-ended queue ([deque](https://en.wikipedia.org/wiki/Double-ended_queue))** is an ordered collection that generalizes both stacks and queues.  A deque allows insertion and removal at both the *front* and the *back*.  The Java `interface` below lists the operations required by the deque abstract data type.

```java
public interface Deque<E> {
  /// Inserts a new element at the front of the queue.
  /// Requirement:  `element != null`
  void pushFront(E element);

  /// Inserts a new element at the front of the queue.
  /// Requirement:  `element != null`
  void pushBack(E element);

  /// Removes and returns the front element of the deque.
  E popFront();

  /// Removes and returns the back element of the deque.
  E popBack();

  /// Returns the front element without removing it.
  E front();
  
  /// Returns the back element without removing it.
  E back();

  /// The number of elements currently in the deque.
  int size();

  /// Returns `true` if the deque is empty, otherwise `false`.
  boolean isEmpty();
}
```

Requirements:

1. Your implementation must use an `E[] storage` array with an initial capacity of `2`.

2. You will need to automatically grow the storage array when the current capacity is exceeded.  Use the *doubling* growth strategy to guarantee that `pushFront` and `pushBack` have amortized `O(1)` runtime.

3. All remaining methods (`popFront()`, `popBack()`, `front()`, `back()`, `size()`, `isEmpty()`) should have constant `O(1)` runtime.
