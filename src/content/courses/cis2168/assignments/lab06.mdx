## Problem 3 (Tree Traversals)

When implementing iterators for tree data structures, there several different kinds of [tree traversals](https://en.wikipedia.org/wiki/Tree_traversal).  Every traversal must visit the root, explore the left subtree, and explore the right subtree, but we have a choice of the order that these operations are performed.

### Part A (Pre-Order Traversal)

A **pre-order traversal** traverses parents before children.

1. visit the current node
2. recursively perform a pre-order traversal of the left subtree
3. recursively perform a pre-order traversal of the right subtree

### Part C (Post-Order Traversal)

In a **post-order traversal**, all children are visited before their parents.

1. recursively perform a post-order traversal of the left subtree
2. recursively perform a post-order traversal of the right subtree 
3. visit the current node

The following Java method uses a post-order traversal of a `BinaryTree` to print the data in each node.

```java

}
```
