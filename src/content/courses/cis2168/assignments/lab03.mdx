## Problem 1:  Ordered Lists

It is often useful to maintain a list of data in _sorted_ order.  For example, we might have a list of students enrolled in a class, in alphabetical order.  When students add or drop the class, we want to modify the list while preserving the alphabetical order.

```java
// Example Usage

students.add("Emily")
students.add("Simon")
students.add("Stephanie")

// Contents:  ["Dan", "Emily", "Grace", "Philip", "Simon", "Stephanie"]
```
