## Page Layout Analysis

By using the browser inspector, I was able to determine the following information:

- The `<body>` element has four child elements:
  - `<header>` contains the website name and logo, the article title, and social media icons.
  - `<nav>` contains a table of contents for the article.
  - `<main>` contains the actual 
  - `<footer>` contains the page comments.  (_We'll skip this one!_)
- The `<header>` has two children:
  - One `<div>` for the website name and social icons.
    - This element uses a **Flexbox Layout** to align the page title left and the social icons right.
  - One `<div>` for the article title and publication date.

## Feature #1:  Collapsible Table of Contents

By default, the table of contents is hidden, but if you click it, it will expand!  Using the browser inspector, I learned that this is achieved with the [`<details>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details) element!  No JavaScript required!

```html
<details>
  <summary>Details</summary>
  1. Box Blur
  2. Gaussian Blur
  3. Separable Gaussian Blur
<details>
```

<Image path="/src/assets/cis3308/project01/frostkiwi-toc.png" />

## Feature #2:  Figures with Captions

This blog includes a lot of images, and often the images have their own caption, like they would in a textbook.  Neat!  By using the browser inspector, I learned that this can be achieved with a special element called `<figure>`.

```html
<figure>
  <img
    src="img/intro.png"
    alt="Texture coordinates, also called UV Coordinates or UVs for short"
  >
  <figcaption>
    Effect of "<a href="https://en.wikipedia.org/wiki/Bloom_(shader_effect)" target="_blank">Bloom</a>", one of many use-cases for blur algorithms
  </figcaption>
</figure>
```
