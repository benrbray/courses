This is a short guide to the basics of `git`, which is the standard software used by programmers for **version control**.  The [official `git` website](https://git-scm.com/) has loads of detailed documentation, including:

- [Cheat Sheet](https://git-scm.com/cheat-sheet) -- The most important commands, at a glance.
- [Reference Manual](https://git-scm.com/docs) -- Quickly look up the documentation for any command.
- [Pro Git Book](https://git-scm.com/book/en/v2) -- A detailed guide to working with Git.
