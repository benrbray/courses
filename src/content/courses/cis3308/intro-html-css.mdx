# Box Model

Every element of a web page is a **box**.  A box may contain other boxes, or it may be empty.  Every box consists of four layers, from inside to outside:

- **Content:** The main content of the box, including text, images, and any child content.
- **Padding:** Empty space added between the content and the border, for visual separation.
- **Border:** A line around the padding and content.
- **Margin:** Empty space surrounding the border, padding, and content boxes.

The following from LearnWizy, [Box Model & Layout Basics](https://www.learnwizy.com/tutorials/fsjs/class04) shows the four layers of the CSS Box Model.  The four sides of each layer can be controlled individually via properties like `margin-left`, `padding-top`, `border-bottom`, etc..

## Box Sizing:  `content-box` vs `border-box`

The [`box-sizing`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/box-sizing) property determines how the width and height of boxes are measured.  The default is `content-box`, which means that the `width` and `height` properties include the content, but not the padding, border, or margin of a box.  For example, `.box { width: 100px; border: 10px solid black; }` will create a box `120px` wide.

With `box-sizing: border-box`, the _width_ and _height_ of boxes will instead control the size of the **border box**.  The size of the _content box_ will be determined by subtracting the padding and border, as shown in the image below.

# Layout Algorithms

_Read More:_  MDN, ["Layout Mode"](https://developer.mozilla.org/en-US/docs/Glossary/Layout_mode)

  CSS implements many different **layout algorithms** for determining the position and size of boxes on the page.

  - Normal Flow Layout (including Block Layout and Inline Layout)
  - Table Layout
  - Float Layout
  - Positioned Layout
  - Multi-Column Layout
  - Flexible Box Layout
  - Grid Layout

  For technical details, see MDN, [Layout Algorithms](https://developer.mozilla.org/en-US/docs/Glossary/Layout_mode).

## Normal Flow

The default layout algorithm is **normal flow**.  This algorithm distinguishes between two kinds of elements:

* **Block Elements** consume all available horizontal space, and are stacked in the _block direction_ (top to bottom) in the same order they appear in the HTML.

  - Examples:  `<p>`, `<h1>`, `<ul>`, `<ol>`, `<table>`, `<blockquote>`
  - Use a `<div>` if you need a generic block container.

* **Inline Elements** are flow in the _inline direction_ (left to right) like text.  By default, they take up only as much space as needed to display their contents.

  - Examples:  `<strong>`, `<em>`, `<a>`
  - Use a `<span>` if you need a generic inline container.

You can use the [`display` property](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/display) to change whether an element displays inline or as a block.

## Table Layout

Historically, the table layout was the only way to achieve complex page layouts.  

- The use of tables for page layouts is **no longer recommended**.
- Instead, use a more modern layout like **flexbox** or **grid** to lay out your pages.
- Only use the table layout if you need to display tabular data (like a spreadsheet).

## Float Layout

Use the [`float:` property](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/float) to enable _text wrapping_ around an element, as in a traditional magazine layout.
