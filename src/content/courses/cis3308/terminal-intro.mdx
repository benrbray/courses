---
title: Useful Terminal Commands
course: cis3308
---

- `cd <PATH>` change directory
- `pwd` print absolute path of current directory
- `ls` list contents of current directory
- `ls -al` list current directory, including hidden files
- `mkdir <PATH>` make directory
- `cat <FILE>` show contents of a file
- `touch <FILE>` create a file, or if it exists, update its timestamp
