## Course Description

This project-based course is an introduction to modern, full-stack web development. Due to the small class
size, we will adjust the pace and content of the course to the interests of participating students.  The main topics will be:

- HTML, CSS
- JavaScript Programming
- User Interaction & Events
- Reactive Web Pages (ReactJS)
- TypeScript Programming
- Web Servers, Client-Server Communication
- Databases, State, Authentication
