## Course Topics

Software Engineering

- Git and Version Control
- Command Line Fluency
- Separation of Concerns
- Using the browser inspector

Frontend

- HTML
  - Semantic HTML
  - Accessibility
  - `data` attributes
- CSS
  - box model
  - measurements (`pt`, `px`, `em`, `rem`)
  - margin and padding
  - `flexbox` and `grid` layouts
  - adaptive webpages
- Images and SVG
- Document Object Model
- Canvas
- Audio and Video

JavaScript Programming

- lambda functions
- `===` and `!==`
- objects, prototypes, and classes
- callbacks and higher-order functions
- closures and scope
- objects
- `this`
- `async`/`await` and Promises
- events
- Fetch API
- Temporal API
- `npm`

TypeScript Programming

- interfaces
- record types
- structural types
- polymorphism

Design Patterns

- Model, View, Controller
- Requests and Response
- JSON
- APIs and REST
- HTTPS and HTTP

Backend

- C#
- Logins & Password Security
- Sessions
  - Browser Refresh
- Idempotent Requests, Form Resubmission

Web Concepts

- Cookies
- Local Storage

Database Concepts

- SQL

Reactive Web Pages

Advanced Topics

- Server Side Rendering vs. Client Side Rendering
- Web Workers
- Web Sockets
- WebGL
- WASM

Dark Patterns

- Websites without URLs
- Back button hijacking
- Async request that blocks page navigation
- Scroll Hijacking
