Problem 1: Ordered Lists

It is often useful to maintain a list of data in sorted order. For example, we might have a list of students enrolled in a class, in alphabetical order. When students add or drop the class, we want to modify the list while preserving the alphabetical order.

In this problem, you will implement an OrderedList<E> class that works with any datatype E that implements the Comparable interface. A class definition with the required methods is shown below.

Internally, your implementation should use a java.util.LinkedList to store elements of the list. Java’s LinkedList class implements the List abstract data type using a doubly-linked list. Just like our example from class, the Node used internally by LinkedList is private, so we cannot manually traverse the list with .next and .prev like we did in class. Instead, the LinkedList.listIterator() method returns a ListIterator which can be used to traverse the list in both directions (forwards and backwards).

Question: What is the difference between a java.util.ListIterator and a regular java.util.Iterator?

Part A (Implement OrderedList.add())

Your implementation of add(element) should use a ListIterator to find the first element in the OrderedList larger than element, according to Comparable<E>.compareTo(). Using the ListIterator.add() method, insert the new element before the first larger element.

Part B (Implement Remaining Methods)

The implementation for the remaining methods get, size, remove, and iterator is simpler. For most of these, you can simply call existing methods on the private LinkedList!

Part C (Testing)

Write a short program that demonstrates that the behavior of your OrderedList is correct. You should test at least the add and remove operations.
