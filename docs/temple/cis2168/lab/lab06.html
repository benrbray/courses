Problem 1 (Measuring Trees)

For this problem, use the following BinaryTree class.

Part A (Size)

Part B (Height)

The height of a tree is the length of the longest path from the root to a leaf node of the tree. Implement a recursive function named height that calculates the height of a BinaryTree.

Problem 2 (Invariants)

Part A (Binary Search Tree Invariant)

Recall that a Binary Search Tree (BST) is a binary tree that satisfies the Binary Search Tree Invariant: Every node n must be larger than its left subtree but smaller than its right subtree. Implement a function isBinarySearchTree which returns true if the given BinaryTree satisfies the BST invariant, and false otherwise.

Part B (Heap Invariant)

Recall that a Max-Heap is a binary tree that satisfies the Max-Heap Invariant: Every node n must be greater than or equal to all elements in both its left and right subtrees. Implement a function isMaxHeap which returns true if the given BinaryTree satisfies the Max-Heap invariant, and false otherwise.

Submit: Your implementation of isBinarySearchTree and isMaxHeap in a file named Problem2.java.
