Example: Comparator Interface

In Java, a class may only provide one implementation for each interface, so our Comparable<T> approach will not work if we wish to sort the same data in two different ways. Instead, there is a different interface named java.util.Comparator<T>, whose compare() method takes two values of type T and compares them.

As an example, we could define two different ways to sort a list of numbers by defining two classes SmallestToLargest and LargestToSmallest that implement Comparator<T> in two different ways.
