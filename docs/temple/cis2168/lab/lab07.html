Problem 2 (Selection)

The Selection Problem is concerned with selecting the kth smallest element from a set of N distinct numbers.

  • Input: A set A of N distinct numbers and an integer k, with 1 <= k <= N.
  • Output: The element x ∈ A that is larger than exactly k - 1 other elements of A.

For example, Select(A=[6,24,7,8,1,4], k=3) should return 6, because there are exactly k-1 = 2 numbers in the list smaller than 6, namely 1 and 4.

Part A (O(N log N) Solution)

Propose an algorithm for solving the selection problem that runs in worst-case O(N log N) time. You can submit either a Java implementation, or just a pseudo-code description of your algorithm. Include an explanation about why you believe your solution will run in O(N log N) time.

(Hint: You can re-use any of the sorting algorithms we discussed in class as one step of your algorithm.)

Part B (Solution with Partitioning)

In this part, you will use the partition operation from quicksort to design a linear-time algorithm for the selection problem. Accordingly, the algorithm will be called quick-select.

To get started, recall that after using partition on an array, the pivot element will always be in its final, correct position. The diagram below shows the steps taken by partition([6,8,3,7,4,1,2,5,0,9]) when pivotIdx = 0.

After partitioning, the pivot value has moved to pivotIdx = 6. There are exactly 6 smaller elements, all located to the left, and exactly 3 larger elements, all located to the right. The pivot is already in its final, sorted location even if the rest of the array is not yet sorted.

This observation is helpful for the Selection Problem because if we are looking for the 6th smallest element, we can already stop and return the pivot value! Otherwise, if we’re looking for the 4th smallest, we know it must lie in the left partition. If we’re looking for the 8th smallest, we know it must lie in the right partition. So, we can solve the Selection Problem by repeatedly calling partition!

Implement the quickSelect algorithm by repeatedly calling partition on the input array. You can use either iteration or recursion. You will need to carefully manage array indexes on each step. You may want to use the quickSelect signature defined above as a wrapper for a different recursive function that takes additional arguments like start and end, just as we did for quickSort.

For this problem, feel free to reference any human-authored resources you can find online about the quick-select algorithm. (However, I strongly recommend seeing if you can solve it yourself, before looking online for help!)
