Lab #8: Maps

Reminder: Map Abstract Data Type

Problem 1 (Implement SortedArrayMap)

Implement the Map abstract data type using a sorted array list. Try to think it through on your own first, then refer to our SortedArraySet implementation if you get stuck.

Problem 2 (TrieMap Iterator)

Implement the Iterator<String> interface for our TrieMap class. The iterator should emit all of the keys of the TrieMap. You are free to decide which order the keys appear.
