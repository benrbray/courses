Functional Interfaces

In Java, any interface with a single abstract method is called a functional interface. Lambda expressions can be used to create new implementations of any functional interface.

The @FunctionalInterface annotation is optional to express our intent to whoever is reading the code, and to guard against unintended breaking changes to the functional interface in the future.

Problem #3: ElasticArray Growth Strategies

During class, we built ElasticArray<T>, which uses an ordinary T[] array to implement the List<T> abstract data type. Whenever the user exceeds the capacity of the fixed-size storage array, our class allocates a new, larger storage array to make room for new elements. We left one question unanswered: How much larger should we make the new storage array? We came up with several different growth strategies, including:

  • Additive: When we exceed capacity, always create room for at least N=1000 more elements.
  • Doubling: When we exceed capacity, double the size of the storage space.

Modified ElasticArray.java

In this problem, you will measure the speed of all three growth strategies and report which one performs best on your machine. To help, the starter code includes a new version of ElasticArray.java with the following modifications:

  • ElasticArray now defines an internal functional interface named GrowthStrategy.
  • The ElasticArray constructor now takes a GrowthStrategy as parameter.
  • The chosen growth strategy is stored in a private field growthStrategy, which is used by the ensureCapacity() method to determine the new storage capacity.
