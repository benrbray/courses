Project #1: HTML and CSS

Part 1: Choose a Website

First, choose a website that you think has an interesting page layout. If you can’t think of a website, you might find inspiration by visiting Hacker News and opening a few of the linked articles.

Part 2: Make a Sketch of the Page Structure

Use the browser inspector to investigate the HTML & CSS of the entire page. Make a rough sketch showing how the page is divided into a hierarchy of boxes. Make note of any interesting page layouts you find (for example: Flexbox, Grid, Masonry).

Use any software you like to create your sketch (PowerPoint, Google Slides, Canva, Figma, Microsoft Paint, etc.). If you prefer, a scan of a hand-drawn diagram is also acceptable.

Part 3: Analyze 3 Interesting Features

Choose at least three interesting features of the website that you think might be fun to reproduce.

  • Include a screenshot demonstrating each feature.
  • Use the browser inspector to understand how each feature is achieved with HTML and CSS, and explain your findings.

Part 4: Clone the Website

The next step is to build a simple clone of the website you chose!

  • Your clone must match your sketch and your description of the original page’s layout.
  • Your clone must include faithful re-implementations of all three features you chose.

Publish your website clone publicly to the GitHub Pages website we set up for Project #0.

Part 5: Submit to Canvas (Deadline: Friday, September 25 @ 3:10pm)

Your final submission should include three parts:

  • A pdf file with your written report.
  • A pdf file with any slides you used for your presentation.
  • A url for the website where your clone is hosted (e.g. username.github.io/cis3308/project01)

If you prefer, you can submit the written portion and the slideshow as a single PDF file.

Part 6: Present In-Class

You will present your results in-class on Friday, September 25. Your presentation should last between 10-15 minutes and showcase your page layout analysis as well as how you implemented your clone.

Page Layout Analysis

By using the browser inspector, I was able to determine the following information:

  • The <body> element has four child elements:
    • <header> contains the website name and logo, the article title, and social media icons.
    • <nav> contains a table of contents for the article.
    • <main> contains the actual
    • <footer> contains the page comments. (We’ll skip this one!)
  • The <header> has two children:
    • One <div> for the website name and social icons.
      • This element uses a Flexbox Layout to align the page title left and the social icons right.
    • One <div> for the article title and publication date.

Feature #1: Collapsible Table of Contents

By default, the table of contents is hidden, but if you click it, it will expand! Using the browser inspector, I learned that this is achieved with the <details> element! No JavaScript required!

Feature #2: Figures with Captions

This blog includes a lot of images, and often the images have their own caption, like they would in a textbook. Neat! By using the browser inspector, I learned that this can be achieved with a special element called <figure>.

Feature #3: Header with Icon, Title, and Socials

The header of this website has several parts, and it’s not immediately obvious how to achieve this layout!

  • The header includes both the blog name and the title of the article.
  • The blog name is aligned to the right, while the social media icons are aligned to the left.
