Project #1: HTML and CSS

(this is a draft – more details will be added to this project spec soon!)

Part 1: Choose a Website

First, choose a website that you think has an interesting page layout. If you can’t think of a website, you might find inspiration by visiting Hacker News and opening a few of the linked articles.

Part 2: Analyze Your Website

  • Choose at least three interesting features of the website that you think might be interesting to reproduce.
  • Use the browser inspector to understand how those elements are structured with HTML, and how CSS influences their appearance.

Part 2: Website Clone

  • Build a simple clone of your chosen website.
  • Your clone must match the structure of the original page.
  • Publish the clone as a new page on your GitHub pages site.
  • On your GitHub homepage, include a link to the new page (e.g. username.github.io/project01.html)

Project Presentation

You will present your results in-class on Friday, September 25. Be prepared to spend 15-20 minutes discussing the structure of the original website, and which elements you chose to clone.
